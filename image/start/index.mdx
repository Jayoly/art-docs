## 什么是 AI 镜像

AI 镜像是可在 AutoDL 计算环境中运行的 Docker 镜像，可以理解为预先打包好的软件运行环境。用户可以基于 GitHub 托管的项目代码，在上游项目基础上配置依赖、算法、模型和启动环境，制作成可复用的镜像，减少从零搭建环境和管理模型的工作。

镜像的具体内容由制作者决定，可能包含项目代码、依赖库、运行配置或模型文件。使用前请查看镜像页面和制作者提供的说明，了解镜像功能、启动方式及资源要求。


## 镜像如何分享和复用

用户可以在 [AutoDL.com](https://www.autodl.com/) 上制作镜像，并将镜像公开分享到[AutoDL.art](https://www.autodl.art/image)。镜像公开后，其他用户可以在 AutoDL 的机器上选择该镜像创建实例，复用其中已经配置好的环境和内容。

使用者通常不需要重新安装镜像中已包含的依赖或重复配置环境。实例创建后，再根据镜像说明启动和使用对应项目。

<Note>
镜像是用于创建运行环境的模板，不是正在运行的实例。使用镜像时仍需按平台流程选择机器并创建实例；镜像具体使用方法以镜像说明文档为准。
</Note>

## 镜像与 GitHub 项目的关系

GitHub 项目通常提供源代码；AI 镜像则是在项目基础上打包好的运行环境及相关内容。镜像可能额外包含依赖、算法模型和启动配置，方便用户直接在 AutoDL 机器上运行。

GitHub 项目更新后，不代表已有镜像会同步更新。镜像内容以制作者发布的版本、更新时间和说明为准。

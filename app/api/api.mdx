## 接口地址与鉴权

应用 API 服务端地址为 `https://www.autodl.art`。调用时将服务端地址与下方接口路径拼接为完整 URL。

### 获取 Token

登录 [AutoDL 控制台](https://www.autodl.com/console/center/settings/token)，依次进入 「账号」 → 「设置」 → 「[开发者 Token](https://www.autodl.com/console/center/settings/token) 」获取 Token。

在请求 Header 中通过 `Authorization` 传入 Token：

```http
headers = {"Authorization": "填写您的token"}
```

<Danger>请妥善保管开发者 Token，不要将其提交到公开代码仓库或分享给他人。</Danger>

## 创建应用实例

`POST /api/v1/adl_dev/dev/instance/pro/create`

<Note>创建的实例默认采用按量计费方式，API 暂不支持选择其他计费方式。</Note>

### 请求参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `data_center_list` | 否 | 地区列表。默认由系统自动选择；`westDC3` 表示西北区，`beijingDC2` 表示北京区。 |
| `req_gpu_amount` | 是 | GPU 数量，范围为 1–4。 |
| `expand_system_disk_by_gb` | 是 | 系统盘扩容大小，单位为 GB，范围为 0–500。 |
| `gpu_spec_uuid` | 是 | 算力规格 ID，参见本文末尾的 GPU 算力规格 ID 对照表。 |
| `application_uuid` | 是 | 应用 UUID，可在网页应用详情中查看。 |
| `application_version` | 是 | 应用版本；填写 `latest` 时使用最新版本。 |
| `instance_name` | 否 | 实例备注名。 |
| `start_command` | 否 | 实例开机后执行的命令。命令执行失败不会影响实例开机，也不会导致实例关机。 |

### 请求Body示例

```json
{
  "data_center_list": ["westDC3", "beijingDC2"],
  "req_gpu_amount": 1,
  "expand_system_disk_by_gb": 0,
  "gpu_spec_uuid": "pro6000-p",
  "application_uuid": "J1c7lsvbq5",
  "application_version": "latest",
  "instance_name": "API创建的实例",
  "start_command": "sleep 1"
}
```

### 返回Body示例

```json
{
  "code": "Success",
  "data": "pro-76419909953e", //创建出的应用实例ID
  "msg": "",
  "request_id": "983edb8c8c8553db1115d51fb2758ae8"
}
```

## 开机应用实例

`POST /api/v1/adl_dev/dev/instance/pro/power_on`

### 请求参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `instance_uuid` | 是 | 应用实例 ID。 |
| `payload` | 是 | 开机模式，填写 `gpu` 表示有卡开机；API 暂不支持无卡开机。 |
| `start_command` | 否 | 实例开机后执行的命令。命令执行失败不影响实例开机；此参数会覆盖创建实例时设置的命令。 |

### 请求Body示例

```json
{
  "instance_uuid": "pro-759127a8714f",
  "payload": "gpu",
  "start_command": "sleep 1"
}
```

### 返回Body示例

```json
{
  "code": "Success",
  "data": null,
  "msg": "",
  "request_id": "2a8504ac55fece996ace6deeb98e7fe5"
}
```

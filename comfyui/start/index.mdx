ComfyUI API 功能是 AutoDL 将 ComfyUI 工作流进行包装后暴露工作流核心参数进行推理的 API 服务。你可以通过网页在线调用，或在自己的程序中发送 HTTP 请求，使用工作流生成图片、视频等结果。

## 功能亮点

- 即开即用：无需繁琐部署与环境配置，通过 API 即可直接调用 MiniMax H3 模型，快速开启视频生成。

- 按量付费：根据实际生成的视频时长计费，用多少付多少，成本清晰可控。

- 参数灵活：开放工作流核心参数，支持按需传入提示词、图片、视频等输入内容，灵活控制生成效果。

- 轻松集成：提供标准 HTTP API 接口，可快速接入自有应用、业务系统及自动化工作流。


<Note>ComfyUI API 使用的是平台提供的工作流接口，不等同于在自己的实例中启动 ComfyUI 服务。具体可用工作流、参数和价格以 AutoDL Art 页面实时展示为准。</Note>

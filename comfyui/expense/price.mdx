ComfyUI API 视频生成按实际调用生成的视频时长计费。工作流、输出尺寸等因素可能影响单价，请以 [ComfyUI API 页面](https://www.autodl.art/large-model/comfyui)展示的实时价格和提交时页面说明为准。

## 计费公式

```text
结算费用 = 计费视频时长（秒） × 对应单价（元/秒）
```

例如，若某工作流当前选择的输出规格单价为 `P` 元/秒，生成视频计费时长为 `T` 秒，则本次费用为 `T × P` 元。此处 `P` 应以调用页面对该工作流和规格显示的价格为准。

## 计费注意事项

- 单价可能因工作流、模型、视频尺寸或其他生成选项而不同；提交前请核对当前工作流的价格说明。
- 本页公式说明的是视频生成按秒计费的情形。若特定工作流展示了其他计费单位或规则，应以该工作流和平台页面的实时说明为准。
- 任务状态、生成时长和费用明细可结合[调用日志](/comfyui/api/log)及账户账单核对；实际结算以 AutoDL Art 账单为准。

## 令牌与鉴权

### 创建哪种 Token 才能调用 ComfyUI API？

在[令牌管理](https://www.autodl.art/large-model/tokens)创建 Token 时，分组选择 **ComfyUI**。调用请求时将 Token 放入 `Authorization` 请求头。详细步骤参见[快速开始](/comfyui/start/quickstart)和[API 调用文档](/comfyui/api/api)。

### 请求提示鉴权失败怎么办？

确认 Token 未被删除或禁用、请求头名称为 `Authorization`、请求中使用的是完整 Token，并且 Token 属于 ComfyUI 分组。不要把 Token 放到 URL、公开代码仓库或截图中。若仍失败，可在令牌管理中重新创建 Token 后再试。

## 工作流与任务

### 每个工作流的请求参数都相同吗？

不相同。提交接口和查询流程一致，但工作流 ID、参数名、类型、必填项和可选值可能不同。请从工作流详情或在线调用弹窗复制对应参数，不要照搬其他工作流的请求体。

### 提交任务后为什么没有立即返回图片或视频？

ComfyUI API 使用异步任务流程。提交接口会先返回任务 ID（`data.task_id`），之后需要调用结果查询接口，直到任务完成，再从 `data.results` 获取结果。详情见[API 调用文档](/comfyui/api/api)。

### `QUEUED` 或 `RUNNING` 状态表示什么？

`QUEUED` 表示任务正在排队，`RUNNING` 表示任务正在执行。请稍后再次查询任务状态。生成耗时会因工作流和任务不同而变化；不要因等待而重复提交相同任务。

### 任务失败或 `results` 为空怎么办？

先确认任务是否已进入终态。若状态为 `FAILED`，查看查询响应或[调用日志](/comfyui/api/log)中的错误信息，再核对工作流 ID、必填参数、参数格式及取值范围。任务仍在排队或执行时，结果列表为空属于处理中状态。

### 任务长时间处于排队或执行状态

任务状态可能先显示 `QUEUED`（排队中），随后变为 `RUNNING`（执行中）。根据工作流耗时适当间隔后再次查询，并结合日志中的状态变化判断进度。不要高频重复提交同一任务，以免产生重复任务或费用。


### 关闭在线调用窗口后还能查询任务吗？

关闭弹窗后，当前页面中的在线查询流程会中断。若已记录 `task_id`，可按[API 调用文档](/comfyui/api/api)中的结果查询接口继续查询；也可查看[调用日志](/comfyui/api/log)定位该次请求。

## 结果与计费

### 生成结果链接失效怎么办？

结果资源 URL 有效期为 24 小时。任务成功后请尽快下载保存；如果链接已过期，需要重新提交生成任务。

### ComfyUI API 如何计费？

视频生成按计费视频时长和对应单价结算，实际单价可能随工作流和输出规格变化。请查看[计费规则](/comfyui/expense/price)及 ComfyUI API 页面当前显示的价格；最终以账单为准。



### 找不到调用记录

- 确认登录的是发起调用的 AutoDL Art 账号。
- 调整筛选条件和时间范围，并确认提交请求确实已发出。
- 如果通过程序调用，检查请求地址、网络错误和 HTTP 响应；提交成功后记录返回的 `task_id`。

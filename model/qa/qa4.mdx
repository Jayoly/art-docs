## 价格与费用

### 为什么会冻结金额

大模型消费金额先冻结后扣除，所以使用时看到冻结金额，会在下一个计费时间点会扣除。

### 如何查询模型单价和计费方式

各模型的当前单价以[模型广场](https://www.autodl.art/large-model/market)页面显示为准。大模型 API 的计费规则和计算方式请查看[计费规则](/model/expense/price)。

### 文本模型的费用如何计算

一般语言模型根据输入 Token 和输出 Token 分别计费。部分模型会按照本次请求的输入 Token 数量采用阶梯单价；Claude 系列还可能产生缓存写入或缓存读取费用。具体单价、阶梯范围及实际扣费以网站页面和平台账单为准。

### 为什么账单中的 Token 数量比我输入的文字多

输入用量可能包括系统提示词、当前消息、缓存命中、发送给模型的历史对话和其他请求内容，不只包括输入框中最新的一句话。多轮对话、较长提示词或重复发送上下文都会增加输入 Token 用量。

### 图像或视频生成如何计费

文生图、图生图、文生视频和图生视频等模型通常按生成调用计费，单价可能因图像尺寸、视频尺寸、时长或其他生成参数而不同。请以模型页面显示的实时价格和账单明细为准，详情见[计费规则](/model/expense/price)。

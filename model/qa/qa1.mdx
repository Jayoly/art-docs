## 模型名称或接口调用

### 提示模型不存在或不可用

请前往[模型广场](https://www.autodl.art/large-model/market)复制模型的完整名称，并检查请求中 `model` 字段的大小写、连字符和版本号。模型名称应与页面显示一致；如果模型需要指定接口协议，请使用该模型页面提供的对应端点。

### 提示 401 或认证失败

请检查以下内容：

1. 使用的是 AutoDL「[令牌管理](https://www.autodl.art/large-model/tokens)」中创建的有效 Token。
2. 请求发送给了正确的 API 地址，且没有把 API Key 与其他平台的密钥混用。
3. API Key 前后没有多余空格或换行。使用兼容客户端时，通常只填写 Token 本身，不要手动添加 `Bearer ` 前缀。
4. Token 未被删除、禁用或过期。

### 提示 404 或接口路径不存在

先确认客户端使用的接口协议与模型端点匹配。OpenAI 兼容接口的 Base URL 通常为 `https://www.autodl.art/api/v1`；Anthropic 兼容接口应使用对应的 Anthropic 地址。SDK 的 Base URL 与直接发送 HTTP 请求时的完整接口路径不同，不要将 `/chat/completions` 重复拼接到 SDK 的 Base URL。

### 提示 400 或请求参数不支持

检查请求体格式、接口协议和模型支持的参数。不同模型支持的参数与能力可能不同；如果请求包含图像、音频、工具调用或特定采样参数，请确认所选模型及当前端点支持该能力，并先用一条简单的纯文本请求进行验证。

### 提示 429 或请求被限流

查看错误信息中给出的限制原因和重试提示。可以先降低并发或请求频率，等待后再重试；如果提示与额度或账户状态有关，请检查令牌设置和平台账单。不要在未确认原因时持续高频重试。

### 流式调用没有显示完整内容

确认客户端按流式格式读取响应，而不是等待普通 JSON 返回。使用 SDK 时检查是否启用了 `stream`，并在循环中逐段读取内容；如果只想验证接口连通性，可以先关闭流式输出，发送一条简短请求。

### 提示上下文长度超限

缩短本次输入，并减少发送的历史对话、系统提示词或附加内容。多轮对话通常会重复携带上下文；请同时确认模型支持的上下文长度，并以模型页面显示的信息为准。

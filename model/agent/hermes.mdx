Hermes Agent 是一个可扩展的 AI Agent。通过配置 AutoDL 的 OpenAI 兼容接口，你可以让 Hermes 使用 AutoDL 提供的大模型。

## 前置准备

1. 安装 Node.js 和 npm。
2. 前往「大模型」->「[令牌管理](https://www.autodl.art/large-model/tokens)」创建并复制 `API_KEY`。
3. 前往「[大模型](https://www.autodl.art/large-model/market)」页面复制要使用的模型名称。

<Note>
下方配置中的 `<你的API_KEY>` 和 `<模型名称>` 需要替换为 AutoDL 页面中的实际值。
</Note>

## 安装 Hermes

### Windows

在 PowerShell 中执行：

```PowerShell
irm https://hermes-agent.nousresearch.com/install.ps1 | iex
```

### Linux 和 macOS

在终端中执行：

```Shell
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

安装完成后，检查 Hermes 是否可用：

```Shell
hermes --version
```

<Tip>
Windows 用户也可以在 WSL 中按照 Linux 的方式安装和配置 Hermes。
</Tip>

## 方式一：使用配置向导

安装完成后运行：

```Shell
hermes model
```

在向导中按照以下方式填写：

1. 选择 **Custom**、**OpenAI-compatible** 或类似的自定义服务商选项。
2. API Base URL 填写 `https://www.autodl.art/api/v1`。
3. API Key 填写 AutoDL 令牌管理页面获取的 `API_KEY`。
4. Model ID 填写 AutoDL 大模型页面中的完整模型名称。
5. 保存配置并将该模型设为默认模型。

<Warning>
Base URL 只填写到 `/api/v1`，不要添加 `/chat/completions`。API Key 只填写 AutoDL Token，不要填写 `Bearer ` 前缀。
</Warning>

## 方式二：手动配置

Hermes 的配置目录通常位于：

```text
Windows: %USERPROFILE%\.hermes\
Linux:   ~/.hermes/
macOS:   ~/.hermes/
```

在配置目录中创建 `.env` 文件，写入：

```dotenv
AUTODL_API_KEY=<你的API_KEY>
```

然后编辑同一目录下的 `config.yaml`，加入或修改以下内容：

```yaml
model:
  default: <模型名称>
  provider: custom
  base_url: https://www.autodl.art/api/v1
  api_key: ${AUTODL_API_KEY}
```

如果 `config.yaml` 中已经存在 `model` 配置，请只修改对应字段，不要重复添加多个 `model` 节点。

### 配置项说明

| 配置项 | 说明 |
| --- | --- |
| `default` | AutoDL「大模型」页面中的完整模型名称 |
| `provider` | 自定义 OpenAI 兼容服务商 |
| `base_url` | AutoDL OpenAI 兼容接口地址 |
| `api_key` | 从 `.env` 文件读取 AutoDL Token |

## Windows 配置示例

Windows 配置文件路径为：

```text
%USERPROFILE%\.hermes\.env
%USERPROFILE%\.hermes\config.yaml
```

`.env` 内容：

```dotenv
AUTODL_API_KEY=<你的API_KEY>
```

`config.yaml` 内容：

```yaml
model:
  default: <模型名称>
  provider: custom
  base_url: https://www.autodl.art/api/v1
  api_key: ${AUTODL_API_KEY}
```

## Linux 和 macOS 配置示例

Linux 和 macOS 配置文件路径为：

```text
~/.hermes/.env
~/.hermes/config.yaml
```

`.env` 内容：

```dotenv
AUTODL_API_KEY=<你的API_KEY>
```

`config.yaml` 内容：

```yaml
model:
  default: <模型名称>
  provider: custom
  base_url: https://www.autodl.art/api/v1
  api_key: ${AUTODL_API_KEY}
```

## 启动 Hermes

完成配置后，在终端运行：

```Shell
hermes
```

发送一条简单消息，例如：

```text
请介绍一下你自己。
```

如果 Hermes 能够正常返回回答，说明 AutoDL Token 和模型配置成功。

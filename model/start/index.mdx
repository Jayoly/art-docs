**大模型 API** 可以让您无需部署、直接调用主流大模型API，包括GLM、Kimi、MiniMax、Qwen、DeepSeek、Seedance、Kling 等。

## 功能亮点

- 即开即用：无需等待，直接通过 API 调用 GLM-5、Kimi、MiniMax、Qwen、DeepSeek 等热门模型。

- 按量付费：仅为实际使用的 Token 付费，AutoDL 会员享受超低折扣。

- 模型丰富：持续接入主流模型，满足对话、写作、翻译、代码生成等多样场景。

- 轻松集成：提供标准 API 接口，快速接入您的应用或工作流，开发更高效。

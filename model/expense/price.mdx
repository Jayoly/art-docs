## 计费单价

各个模型的单价请以网站显示的实时价格为准。不同模型、不同能力类型、不同上下文长度或不同生成规格，可能对应不同单价。

<Note>
页面中的计费公式用于说明计费方式，实际扣费以平台账单和网站展示的实时价格为准。
</Note>

## 语言模型计费

一般语言模型以输入 Token 和输出 Token 的数量作为使用量进行计费。

结算费用：

```text
输入费用 = 输入 Token 数量(百万 Token) × 输入单价(元/百万 Token)
输出费用 = 输出 Token 数量(百万 Token) × 输出单价(元/百万 Token)
总费用 = 输入费用 + 输出费用
```

其中：

| 项目 | 说明 |
| --- | --- |
| 输入 Token | 用户输入、系统提示词、历史上下文等发送给模型的内容 |
| 输出 Token | 模型生成并返回的内容 |
| 输入单价 | 模型输入 Token 的单价，单位为元/百万 Token |
| 输出单价 | 模型输出 Token 的单价，单位为元/百万 Token |

## 阶梯计费

部分语言模型会按照上下文长度进行阶梯计费。此类模型会在语言模型基础计费规则上，根据本次请求的输入 Token 数量匹配对应阶梯单价。

例如：

| 本次输入 Token 数量 | 输入单价示例 |
| --- | --- |
| 小于 32000 | 4 元/百万 Token |
| 大于等于 32000 | 8 元/百万 Token |

结算时会按照本次请求命中的阶梯价格计算输入费用，输出费用仍按照该模型对应的输出单价计算。

<Warning>
上表仅用于说明阶梯计费方式，不代表实际价格。具体阶梯范围和单价请以网站显示的价格为准。
</Warning>

## Claude 系列模型计费

Claude 系列模型除输入 Token 和输出 Token 费用外，还可能包含 Token 缓存相关费用，包括：

1. 缓存写入（5 分钟）
2. 缓存写入（1 小时）
3. 缓存读取

结算费用：

```text
输入费用 = 输入 Token 数量(百万 Token) × 输入单价(元/百万 Token)
输出费用 = 输出 Token 数量(百万 Token) × 输出单价(元/百万 Token)
缓存写入(5分钟)费用 = 缓存写入(5分钟)Token 数量(百万 Token) × 缓存写入(5分钟)单价(元/百万 Token)
缓存写入(1小时)费用 = 缓存写入(1小时)Token 数量(百万 Token) × 缓存写入(1小时)单价(元/百万 Token)
缓存读取费用 = 缓存读取 Token 数量(百万 Token) × 缓存读取单价(元/百万 Token)
总费用 = 输入费用 + 输出费用 + 缓存写入(5分钟)费用 + 缓存写入(1小时)费用 + 缓存读取费用
```

如果本次调用未产生缓存写入或缓存读取，则对应费用为 0。

## 文生图和图生图计费

### 按次计费

部分模型按调用生图次数进行计费。比如：Qwen-Image、Z-Image-Turbo

结算费用：

```text
总费用 = 生图调用次数 × 单价(元/次)
```

其中，单价可能与用户选择的生成图像尺寸、生成数量、输入类型、模型类型等因素相关，具体以网站显示的实时价格为准。

### 按token计费

部分模型按调用token进行计费。比如：gpt-image-2、nano-banana-2.1

结算费用：

```text
文本输入费用 = 文本输入 Token 数量(百万 Token) × 文本输入单价(元/百万 Token)
图像输入费用 = 图像输入 Token 数量(百万 Token) × 图像输入单价(元/百万 Token)
视频输入费用 = 视频输入 Token 数量(百万 Token) × 视频输入单价(元/百万 Token)
文本输出费用 = 文本输出 Token 数量(百万 Token) × 文本输出单价(元/百万 Token)
图像输出费用 = 图像输出 Token 数量(百万 Token) × 图像输出单价(元/百万 Token)
总费用 = 文本输入费用 + 图像输入费用 + 视频输入费用 + 文本输出费用 + 图像输出费用
```

部分模型token用量会有自动x系数，比如：gpt-image-2.5-sunburst、gpt-image-2.5-flare

```text
token用量 = 文本输入token x 3.35 + 文本缓存输入token x 0.8375 + 图片输入token x 5.36 + 图片缓存输入 x 1.34 + 输出图片token x 20.1
```

其中，单价可能与用户选择的生成图像尺寸、生成数量、输入类型、模型类型等因素相关，具体以网站显示的实时价格为准。

## 文生视频和图生视频计费

### 按秒计费

部分视频生成模型通常按调用生成视频的秒数进行计费。比如：wan3.0-video-prime、MiniMax-H3

结算费用：

```text
总费用 = 生成视频调用秒数 × 单价(元/秒)
```

其中，单价可能与用户选择的生成视频尺寸、时长、模型类型等因素相关，具体以网站显示的实时价格为准。


### 按token计费

部分视频生成模型通常按调用生成视频的token进行计费。比如：doubao‑seedance‑2‑5‑260628、doubao-seedance-2-0-mini-260615

结算费用：

```text
总费用 = 生成视频token用量 × 单价(元/百万 Token)
```

其中，单价可能与用户选择的生成视频尺寸、时长、模型类型等因素相关，具体以网站显示的实时价格为准。

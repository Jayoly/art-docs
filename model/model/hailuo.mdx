## 调用说明

- `API_KEY`请前往「大模型」->「[令牌管理](https://www.autodl.art/large-model/tokens)」页面获取

- `model`请前往「[大模型](https://www.autodl.art/large-model/market)」页面复制model名称

- v1端点（除MiniMax-H3）：https://www.autodl.art/api/v1/minimax/v1/video_generation

  v2端点（MiniMax-H3）：https://www.autodl.art/api/v1/minimax/v2/video_generation


<Note>以下调用以模型`MiniMax-H3`、v2端点为例，请将示例中的 `YOUR_API_KEY` 替换为实际的 AutoDL 密钥</Note>

详见[MiniMax 官方文档](https://platform.minimax.cn/docs/api-reference/video-generation-v2-create)

## cURL 调用

```bash
curl --request POST \
  --url https://www.autodl.art/api/v1/minimax/v2/video_generation \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "一只橘猫坐在窗边，柔和的午后阳光，写实摄影风格"
    }
  ],
  "resolution": "768P",
  "duration": 5,
  "ratio": "16:9"
}
'
```

## Python 调用

```python
import requests

url = "https://www.autodl.art/api/v1/minimax/v2/video_generation"

headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
}

payload = {
    "model": "MiniMax-H3",
    "content": [
        {
            "type": "text",
            "text": "一只橘猫坐在窗边，柔和的午后阳光，写实摄影风格",
        }
    ],
    "resolution": "768P",
    "duration": 5,
    "ratio": "16:9",
}

response = requests.post(url, headers=headers, json=payload)

print("Status:", response.status_code)
print("Response:", response.text)
```

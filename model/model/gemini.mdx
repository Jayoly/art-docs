## 调用说明

- `API_KEY`请前往「大模型」->「[令牌管理](https://www.autodl.art/large-model/tokens)」页面获取

- `model`请前往「[大模型](https://www.autodl.art/large-model/market)」页面复制model名称

- 对话请求端点：https://www.autodl.art/api/v1/gemini/v1beta/models

<Note>以下调用以模型`gemini-3.1-pro-preview`、对话请求端点为例，请将示例中的 `YOUR_API_KEY` 替换为实际的 AutoDL 密钥</Note>

## cURL 调用

```bash
curl --location 'https://www.autodl.art/api/v1/anthropic/v1/messages' \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'anthropic-version: 2023-06-01' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "claude-opus-5-5",
    "max_tokens": 1024,
    "messages": [
      {
        "role": "user",
        "content": "您好！"
      }
    ]
  }'
```

## Python 调用

```python
from google import genai
client = genai.Client(
    api_key="YOUR_API_KEY",
    http_options={"base_url": "https://www.autodl.art/api/v1/gemini/v1beta/models"}
)

response = client.models.generate_content(
    model="gemini-3.1-pro-preview",
    contents="您好！"
)

print(response.text)
```

<Tip>
如果本地尚未安装 google Python SDK，请先运行 `pip install google`。
</Tip>
